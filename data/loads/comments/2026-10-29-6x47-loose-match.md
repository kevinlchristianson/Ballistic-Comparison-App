# Loose match drops Lapua from 6x47 Lapua

- Status: open
- Date: 2026-10-29
- Topic: A record named 6x47 Lapua also matches the bare name `6x47`

## Question

`looseAliasKey` drops the maker word Lapua. The load-bot record `6x47-lapua` (name `6x47 Lapua`) therefore also matches bare `6x47`. Hodgdon's `6 x 47mm` used that same key. Can the loose match keep a name unmatched when dropping the maker word lands on a key another published cartridge uses?

## Context

Hodgdon lists two cartridges. `6X47MM Lapua` is 160 rows, twist 1:8, COL 2.440, trim 1.840, diameter .243. `6 x 47mm` is 50 rows, twist 1:14, COL 2.400, trim 1.840, diameter .243. 4D rents both a 6mm x 47 Lapua reamer and a separate 6mm x 47 on the .222 Remington Magnum (https://4drentals.com/product/reamer-rentals/rifle/6-x-47-6mm222-rem-mag/). That drawing prints case 1.850 and neck 0.266. It does not print a bullet diameter, so this bot did not add a record for it.

The Lapua-named strings should resolve to `6x47-lapua`. Bare community `6x47` is the one the loose match still attaches to that record. Hodgdon's `6 x 47mm` is the .222 Remington Magnum wildcat. Those 50 rows are stored as `6 x 47mm benchrest` so the loose match does not send them to `6x47-lapua`. A name with `(222 Rem Mag)` in parentheses would resolve to `.222 Remington Magnum`, which these loads are not. The notes on the rows quote the printed Hodgdon name.

## Working assumption until answered

Leave `6x47-lapua` in place. The renamed Hodgdon rows stay unmatched until a source prints that wildcat's bullet diameter and case length together, or the resolver can tell the two 6x47 cases apart.
