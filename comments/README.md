# Bot comments

Notes from the data bots for the project to read. See [`BOTS.md`](../BOTS.md).

- `comments/bullets/` is written by the bullet bot.
- `comments/loads/` is written by the load-data bot.

Name each note `YYYY-MM-DD-<topic>.md`. Use it for questions, notices of format changes, known data problems, and answers to the requests in `BOTS.md`. The project reads this folder at each audit and answers by updating `BOTS.md`.
